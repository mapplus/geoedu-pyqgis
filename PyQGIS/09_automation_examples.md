# 09. 자동화 예제

## 학습 목표

- 콘솔에서 검증한 코드를 작은 스크립트로 정리하는 방법을 익힌다.
- 기존 예제 파일을 읽고, 어떤 흐름으로 자동화하는지 이해한다.
- 이후 Processing 스크립팅과 플러그인 개발로 이어질 발판을 만든다.

## 자동화의 기본 흐름

PyQGIS 자동화는 보통 아래 순서로 작성합니다.

1. 입력 레이어를 찾는다.
2. 유효성을 검사한다.
3. 피처를 순회한다.
4. 새 지오메트리나 속성값을 만든다.
5. 결과를 새 레이어나 파일로 저장한다.

## 예제 1. 여러 레이어 불러오기

핵심 포인트:

- 폴더 순회
- 파일명에서 레이어명 만들기
- 반복적으로 레이어 추가하기

## 예제 2. 피처를 다른 지오메트리로 변환

핵심 포인트:

- 입력 레이어의 피처 읽기
- 중심점 계산
- 새 피처 생성
- 출력 레이어에 기록

## 예제 3. 버퍼 생성

핵심 포인트:

- 입력 지오메트리 읽기
- `buffer()` 적용
- 새 폴리곤 결과 저장

## 다음 단계로 연결

이 구조를 이해하면 다음 주제로 넘어가기 쉬워집니다.

- Processing 알고리즘 호출
- 사용자 입력이 있는 스크립트 작성
- 플러그인 메뉴와 버튼 연결
